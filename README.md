# Aura Salon redesign

Modern Next.js redesign for Aura Salon in Reno, Nevada.

## Pages

- Home
- Services
- Aveda
- Our Team
- Gallery
- About
- Contact

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

The visual direction keeps Aura's dark header, green accent color and signature leaf motif while modernizing the typography, spacing, image treatment and page structure. The site uses Aura's existing public salon photography and links the primary booking CTA to the salon's existing SalonBiz booking flow.
